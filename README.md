# Sistema de Registro de Usuários em PHP

## Nome: Paulo Ricardo Sanches

### Descrição
Projeto para a disciplina de Programação III com uso de PHP orientado a objetos, autenticação com sessão e cookies.

### Como executar localmente
1. Clone o repositório
2. Execute um servidor local (ex: Laragon)
3. Acesse `http://localhost:8000` no navegador
